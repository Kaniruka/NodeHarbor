# Domain Docs

This is a single-context repository.

## Before exploring

- Read root `CONTEXT.md`.
- Read relevant decisions under `docs/adr/`.
- If either location is absent, proceed silently.

## Layout

- Domain glossary: `CONTEXT.md`
- System-wide architecture decisions: `docs/adr/`

## Vocabulary

Use canonical terms from `CONTEXT.md` in issues, specifications, tests, hypotheses, and implementation discussions. Avoid synonyms that the glossary explicitly rejects.

## Architecture decisions

If proposed work contradicts an existing ADR, identify the conflict explicitly instead of silently overriding the decision.
